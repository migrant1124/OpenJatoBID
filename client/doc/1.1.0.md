# Jato AI BID v1.1.0 发行说明

> 发布日期：2026-07-12  
> 适用产品：Jato AI BID 用户端（Windows / macOS）、Jato AI BID 管理端（Windows）

---

## 概述

v1.1.0 是 Jato AI BID 的首个正式版本，在保持原有投标工作流不变的前提下，完成了全局视觉焕新、局域网授权管理体系建设、统计能力重构及多项功能增强。

---

## 新功能

### 🎨 全局视觉焕新（Ant Design v6）

- 应用外壳、侧栏、对话框、表单、Toast、Markdown 渲染等全部 UI 统一为 Ant Design System v6 风格。
- 保持原有页面布局、导航结构、业务流程和交互逻辑不变，仅替换视觉表达。
- 不引入 `antd` 依赖，基于现有 Radix 基础组件 + 全局 CSS 令牌实现。

### 🖥️ 独立 Windows 管理端

- 全新独立应用 `Jato AI BID 管理端`，与用户端完全分离的安装包、进程和数据目录。
- 支持系统托盘驻留、单实例运行、开机自启动。
- 提供授权审批、员工与设备管理、运维统计 Dashboard 等完整管理能力。

### 🔐 局域网授权闭环

- 员工通过用户端启动页提交姓名、手机号和设备信息申请授权。
- 管理员在管理端审批/拒绝/续期/撤销，每名员工最多绑定 3 台设备，授权有效期 1 年。
- 本地授权支持离线使用，至少每 30 天连接管理端校验一次。
- 授权和埋点请求完全迁移到局域网管理端，不再访问旧公网地址 `analytics.agnet.top`。

### 👤 管理员认证（内置凭据 + 强制改密）

- 管理端内置单一管理员凭据，安装包随附私有构建配置注入初始用户名/密码。
- 首次登录强制修改密码且不可复用初始凭据；登录后可主动改密。
- 不提供注册、SMTP、忘记密码或自助恢复入口。

### 📊 局域网统计体系

- 客户端埋点优先发送至局域网管理端，离线时本地队列暂存（最多 30 天或 10,000 条）。
- 管理端提供统计总览、客户端与 IP 统计、AI 用量、配置审计、Agent 运行和最近事件等完整看板。
- 公告、资源列表和软件更新检查保留独立公共服务能力。

### 📝 技术方案增强

- **Step03 目录排序**：支持同级拖拽排序，排序时保留已生成正文，切换步骤前询问保存。
- **Step04 全局事实设定**：新增全局事实步骤，两轮 AI 提取项目关键事实，注入后续正文生成 Prompt。
- **Step05 全文一致性审计**：生成完成后自动审计全文一致性，通过精确文本匹配修复冲突，默认开启。
- **Step05 最低字数控制**：支持配置每章节最低字数，生成后自动补足，插入配图前统一校验。
- **Step05 已有方案扩写**：支持导入已有方案进行还原映射、基于原文优化扩写和覆盖审计。
- **暂停/继续**：正文生成支持安全暂停与恢复，保留扩写和配图进度。
- **技术方案 SQLite 存储**：技术方案状态全面迁移到 SQLite，移除旧 JSON 文件存储。

### 🔍 废标项检查增强

- 支持多投标文件并行分析，每条检查结果附带文件归属。
- 主请求改为流式传输，页面支持单项重试。
- 小 Markdown 卡片不再显示"全屏"按钮。

### 📚 标书查重任务化

- 标书查重迁入统一后台任务组体系，与废标项检查、技术方案任务共享任务锁和进度管理。

### 📄 文件解析增强

- DOC/WPS 本地转换自动识别 LibreOffice、WPS Office、Microsoft Word，任一可用即可完成转换。

### 🖼️ 资源管理

- 客户端资源页改为远程接口读取，支持搜索和 Markdown 弹窗查看。
- 管理后台支持资源图片上传和内容管理。

### 🛠️ 开发者工具

- 新增多模块开发者模式文件日志：技术方案、文件解析、标书查重、废标项检查、Word 导出。
- 日志按模块写入 `userData/logs/<module>/*.jsonl`，不记录敏感数据。

### 🔧 OpenCode Agent 增强

- Agent 任务改为全局 FIFO 队列，避免并发冲突导致任务失败。
- 排队任务支持 AbortSignal 取消，顶部状态条显示排队数量。
- Step05 超长原方案还原和优化扩写自动切换 Agent 路径。

---

## 变更与移除

- 移除旧公网授权和离线激活入口。
- 移除"龙猫"可选文本模型入口（历史配置兼容加载和显示）。
- 文本/生图模型服务商"金龙中转站"名称和 API Key 获取链接已更新。
- 关于页隐私声明全文更新，明确业务涉密数据零集中收集原则。
- 管理端移除 SMTP 邮件临时密码方案及相关依赖（`nodemailer`）。

## 技术说明

| 组件   | 技术栈                                                            |
| ---- | -------------------------------------------------------------- |
| 用户端  | Electron 41 + Vite + React 19 + TypeScript + Radix UI + SQLite |
| 管理端  | Electron 41 + Vite + React 19 + TypeScript + Radix UI + SQLite |
| 埋点服务 | Cloudflare Workers + Analytics Engine + D1 + KV + R2           |

- 用户端命令：`cd client; npm ci; npm run build`
- 管理端命令：`cd management; npm ci; npm test; npm run build`
