# Jato AI BID v1.2.0 发行说明

> 发布日期：2026-07-12
> 适用产品：Jato AI BID 用户端（Windows / macOS）、Jato AI BID 管理端（Windows）

## 概述

v1.2.0 重点升级技术方案正文配图链路，并同步调整正文生成配置、SQLite 数据结构和部分界面入口。管理端随本版本提供 Windows 安装包，不包含功能变更。

## 用户端更新

### 正文配图链路

- 新增 Agent 全文图片规划与生成流程，将配图规划、生成和正文写回拆分为独立阶段。
- 新增正文配图规划、生成、远程图片重试及 Mermaid 策略模块。
- 正文生成配置增加 AI 生图上限、HTML 生图上限和对应示例图。
- 配图任务状态和生成结果接入现有后台任务及技术方案存储流程。

### 数据与兼容性

- 技术方案 SQLite 数据库结构升级到 v17。
- 删除“龙猫”文本模型选择入口，历史配置仍可兼容读取和显示。
- Mermaid 生图入口已从界面移除，新配置默认关闭；历史配置仍可兼容读取。

### 界面调整

- 小型 Markdown 卡片不再显示“全屏”按钮。
- 正文编辑页同步适配新的全文配图状态、配置和结果展示。

## 发布范围

- 用户端 Windows：NSIS、MSI 和 ZIP（x64）。
- 用户端 macOS：DMG 和 ZIP（Intel x64、Apple Silicon arm64）。
- 管理端 Windows：NSIS 和 ZIP（x64）。
- 管理端不提供 macOS 安装包。

## 已知限制

- Windows 和 macOS 安装包当前未接入代码签名，系统可能显示安全提示。
- macOS 用户端产物由 GitHub Actions 的 macOS runner 构建，不能在 Windows 本机完成正式构建验证。
