## 1. 这份交付是什么

本包是按当前项目代码样式重建的新增功能 UI 参考和可点击原型，不是已运行的新版 Electron 截图。用于用户评审，再由 Codex 接入真正业务。没有推送、合并、修改分支、打标签、发布软件。

共9张1600×1000 PNG；`prototype.html` 可在解压后用浏览器打开，入口为业务流程，底部“全部画面”可切换页面。需要的图片随包提供，不需安装依赖。模型、安装、删除等按钮仅演示，不实际执行敏感动作。

`audit/ui-validation.json` 为参考原型的渲染与交互检查，不是PPT业务验收。

## 4. 素材真实性

- 第一张 wuhua 封面取自真实 PPTX 的完整页面 XML，CRC验证后用干净PPTX容器重封装，LibreOffice渲染。不是原整包的PowerPoint渲染，母版/主题保真未验证。
- 其余`assets/deck-*.png`、`assets/prompt-*.jpg`为本次仅用于界面排版的示例素材，图内/页脚已标示。不是爬取到的上游实际图库，不代表真实页数或全库通过。
- 更新数量、最近发布、运行状态、项目路径为交互演示数据，不是读取管理端运行数据。
- 生产版必须使用与条目ID、文件版本匹配的真实图。没有真实预览应显示“待准备/加载失败”与重试，不能用示例素材代替。

## 5. 组件与行为合同

### 固定周同步

每7天一次，不提供周期编辑控件。首次启用立即初始化；手动检查与重试不移动锚点；重启只补一个过期检查。管理端退出/关机不能承诺仍在运行。无变化不生成新通知。

### 两中心缩略图

来源侧栏和卡片样式复用现有生图实现。提示词图片区域默认完整显示，可放大；模板首页`object-fit:contain`，16:9/4:3原比例，不能拉伸或裁掉文字。图的加载成功、失败、无图、准备中分别显示；缓存key绑定资源ID+文件hash+页码+预览版本。

大图关闭恢复原筛选、页码与滚动位置。Esc、关闭按钮和键盘可达性必要；原型已验证打开/关闭/搜索路径，生产还需焦点锁定、还原和屏幕阅读器检查。

### 更新弹窗

客户端应用轻量目录与提示词数据后出现，不提前报“已同步”；只展现发布成功的变更。多次版本变化按稳定ID汇总。已读不重弹，制作/导出/确认进行中延后，两个中心不各弹一次。大文件仍按需获取，不能在“知道了”背后下载全库。

### 模板动作

- wuhua有原生页级证据，但本次不等于生产可直接使用的整库检验。原型按钮演示目标操作。
- free目前是视觉参考候选；没有原文件结构证据不能标“原生套用已验证”。视觉参考路线不承诺修改原PPT对象或像素级复原。
- 完整套写、原生编辑、按参考重制三种交付结果不能混称。

### 制作工作区

新增布局仍使用现有组件视觉。源文件权威、页面稳定ID、互斥写锁和候选版本由业务层负责。不是把画布上看起来改了就视为导出已改。宽度不足可折叠Agent，不改原对话模式布局。

### Skill及目录

安装按钮不直接执行自由shell；先解析资源/依赖/权限。删除一次真实确认，不删用户源ZIP/文件夹，不混淆卸载与项目旧版本保留。

系统盘判断来自真实Windows系统卷及最终目标卷，不只看字母C。点击仍然使用有效；普通员工不能写入时清晰报错。改默认目录不迁移旧项目，迁移要另行确认和校验。

## 6. 响应式与图稿边界

基准1600×1000，额外检查1366×900；列表在模块内部滚动，完整内容不必强塞一屏。卡片在窄窗口减少列数，不缩小为不可读文字。画布保持比例。

当前不同系统默认字体度量会导致细小差异，因此图稿是实际CSS约束下的设计参考，不宣称与用户机器截图逐像素一致。

## 7. Codex对齐指令（可直接粘贴）

输入：D1.2规格、此handoff、screens中的九张图及用户确认的调整意见。输出：指定分支上复用现有组件的最终UI和真实功能。约束：版本v1.8.4、分支v1.8.4-架构优化，不另起风格、不推送发布。

第一步，读取现有tokens、侧栏、生图卡片、弹窗与管理端组件，列出复用点及与图稿的差异。以现有代码为主，不用独立原型替换整个应用。

第二步，接入管理端固定周同步和客户端资源协议，输出真实只读计划、变更状态和目录；手动检查不重置周期，客户端无公网回退。

第三步，为生图提示词中心和PPT模板中心绑定真实缩略图与大图，对应资源ID/版本；移除参考稿所有示例配图和假统计，补齐失败和等待状态。

第四步，接入两中心更新概括、项目/模板/Skill/存储操作；输出连通的事件和状态，不用Toast示例代替实际动作，不破坏个人内容和项目版本。

第五步，按验收表完成测试、修复、Windows/Electron视觉与功能验证。明确原型通过和业务通过的区别；未确认的视觉调整先反馈，不自创大范围布局。
