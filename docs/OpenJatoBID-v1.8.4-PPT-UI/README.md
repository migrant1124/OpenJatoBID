## 打开方式

解压后直接打开 `prototype.html`。默认展示业务流程，点击底部“全部画面”查看9张参考图并进入可点击画面。`screens/`保存全部PNG原图。

## 阅读顺序

1. `OpenJatoBID-v1.8.4-PPT-Resource-Center-Spec-D1.2.md`：完整修订规格。
2. `UI-Handoff.md`：现有样式依据、组件与交互规则、各图说明、Codex对齐指令。
3. `Template-Reuse-Assessment.md`：两个模板源的判断、wuhua页级实测与free尚未取得原文件的限制。
4. `audit/`：真实来源页XML、CRC证据、替换测试PPTX和渲染、UI检查。

原型只演示交互，不调用模型、不上传资料、不安装技能、不删除文件，也没有修改原项目。图中除注明的wuhua原生页面外，其他配图和数量是设计示例；正式实现必须绑定真实资源。

固定每周（7天）检查，两个中心必须有可点击图片/PPT首页缩略图。其余本话题已确认功能继续在同一版完整实现，不拆产品阶段。
