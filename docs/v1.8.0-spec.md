## 2. 产品定位

在现有一级 Tab 中新增“生图模式”，与“对话模式”等并列，形成独立、低门槛、中文优先的图片创作工作台。

无需创建招标项目、上传招标文件或生成目录即可使用。不自动读取投标项目事实、知识库资料、正文提示词或公司品牌内容。不把新模块强制接入投标正文插图流程。

仅提供简单模式：不出现简单／专业切换，不预留不可用的专业模式按钮，不要求用户学习无限画布、节点或连线。

## 4. 已确认范围

### 4.1 本版必做

- 一级 Tab“生图模式”，仅简单模式。
- 二级入口“AI 生图”“提示词中心”“我的作品”。
- 文生图、图生图／多参考图生成、图片局部修改。
- 图片反推提示词；反推结果可以继续优化、保存或用于生成。
- 提示词优化，包括原文与优化结果对比、增强点说明，以及用户主动应用。
- 远程参考提示词中文化、检索、更新与复用。
- 我的提示词新增、编辑、删除、收藏、分组、标签与备注。
- 我的常用风格保存、编辑、删除与应用。
- 任务预设，降低普通用户起步难度。
- 作品历史、收藏、生成参数与父子版本来源。
- PNG、JPG、WEBP 图片导出。
- 图片拆层及真实像素分层 PSD 导出。

### 4.2 本版不做

专业模式、无限画布、节点式工作流、视频、音频、多 Agent 协同、复杂插件系统、Illustrator AI／AIT 导出、自动注入公司品牌、与投标正文插图深度联动。

背景移除／专用换背景工具、高清超分、批量变体、一键多尺寸适配为后续储备。用户通过普通图生图描述换背景不受此范围限制，但不得据此新增一个尚未实现的专用工具入口。

### 4.3 防止隐性扩围

“应用内已有文字或简单图形对象应尽量独立导出”是兼容要求，不等于本版要新增完整文字排版器、形状编辑器、矢量工具或 Photoshop 替代品。首版 PSD 的必达目标是可继续加工的真实像素图层。

## 5. 信息架构与页面

```text
生图模式（新增一级入口）
├─ AI 生图（默认创作页）
│  ├─ 中文需求与任务预设
│  ├─ 参考图片与参数
│  ├─ 提示词优化／图片反推
│  └─ 结果预览、继续创作与局部修改
├─ 提示词中心
│  ├─ 参考提示词
│  ├─ 我的提示词
│  └─ 常用风格
└─ 我的作品
   ├─ 历史、收藏与筛选
   ├─ 参数和版本详情
   └─ 图片／PSD 导出
```

保留现有客户端外壳、一级导航风格、标题栏和窗口行为。新模块默认落到 AI 生图；若现有二级菜单机制默认展示入口卡片，应仅为新模块完成必要的定向，不改变其他模块。

“参考提示词”为第三方社区来源时标明来源，不包装成佳图或模型提供商的官方背书。

## 6. 核心流程

**文字创作：**输入需求 → 可选优化并确认应用 → 生成 → 预览 → 下载／收藏／保存提示词。

**参考图创作：**上传参考图 → 标记参考角色 → 补充描述 → 生成 → 局部修改 → 保存新版本 → 导出。

**图片反推：**上传或选中图片 → 反推参考提示词 → 查看并编辑 → 可选优化 → 保存我的提示词或用于生成。

**参考提示词复用：**浏览中文案例 → 选择提示词 → 应用到输入框 → 修改／优化 → 生成 → 保存个人副本。

**设计交付：**选中作品 → 拆分图层 → 预览原图、合成图和各图层 → 导出 PSD → 人工检查后交付。

保存、优化、翻译、反推、应用提示词均不自动触发付费生图。

## 7. 功能要求

### 7.1 文生图

支持中文描述、画幅比例、生成张数、质量档位和风格倾向。目标比例包含 1:1、3:4、4:3、9:16、16:9。具体可用参数应与所接模型真实能力一致，不伪造接口参数。

生成结果自动保存其实际提示词、模型配置引用、实际输出尺寸、生成方式和创建时间。张数部分成功时保留成功结果并明确失败数量。

### 7.2 多参考图

产品目标支持 1–4 张参考图；每张可标记主体、风格、构图或色彩参考。渠道限制小于产品上限时明确提示，不能静默忽略图片。

“保持主体一致性”为尽量保持的创作要求，不承诺绝对一致。必要的参考角色说明应实际进入请求，而不只是显示标签。

### 7.3 局部修改

支持画笔、橡皮、画笔大小、撤销、重做、缩放与修改描述。文案：“涂抹需要修改的区域，再输入你想改成什么。”

保留原图，结果形成新版本；尽量保护非选区。原生遮罩或标注参考方式由真实渠道决定；边缘融合范围、选区外变化检测与验收见实施任务书，不能仅凭界面有遮罩就声称像素保护已实现。

### 7.4 图片反推提示词

功能名称“图片反推提示词”，解释为“根据图片生成参考提示词”。不承诺还原原作者的提示词、随机种子、模型或工作流。

结果包含主提示词、风格、构图、光影、色彩、关键词和画幅建议；中文优先，可提供英文／双语结果。支持复制、编辑、继续优化、保存为我的提示词、应用到生图输入框。

### 7.5 提示词优化

入口：主输入框、反推结果、参考提示词详情和我的提示词编辑。

支持优化、扩写、简化、英文翻译、双语版本及商业海报、产品摄影、写实、插画等风格改写。简单界面默认只突出“优化提示词”，其他动作集中到次级菜单，不新增专业模式。

必须显示原文、优化后内容及主要变化说明。用户确认应用前，不覆盖原文。应保留用户明确的主体、数量、画面文字、尺寸和排除项；存在冲突时展示提示，不自行替用户做业务决定。

### 7.6 参考提示词与中文更新

支持按来源更新、检索、标签筛选、查看原文与中文、使用提示词、另存个人副本。软件启动及运行期间按设定周期检查更新，支持手动刷新和最近同步时间。

“自动更新”不意味着承诺来源逐秒推送。失败时保留上次成功数据；同步不修改正在编辑的输入框，不覆盖个人副本，不改变历史任务快照。中文翻译保留变量、技术参数及画面中用户明确指定的文字。

### 7.7 我的提示词与常用风格

我的提示词支持手动创建，以及从参考库、优化结果、反推结果或作品参数保存。字段包括名称、正文、标签、分组、备注、适用风格、推荐比例、收藏状态。

常用风格保存风格描述、提示词模板、推荐比例、常用参数与备注。应用常用风格时不要悄悄替换用户主体或当前参考图。

复用现有个人提示词能力，扩展用途元数据而非复制第二套互不相通的个人库；不得破坏对话模式原有提示词导入和管理行为。

### 7.8 我的作品

提供作品卡片、历史／收藏筛选和详情。记录文生图、图生图、局部修改来源、使用提示词、参考图及父子版本关系。

支持继续生成、局部修改、反推、保存提示词、下载、收藏、删除与 PSD 导出。删除确认不能连带破坏仍被其他版本使用的资产。

### 7.9 图片与 PSD 导出

PNG／JPG／WEBP 为真实编码转换，不能仅更换扩展名；透明图片转 JPG 时明确背景色处理。

PSD 为真实像素分层，至少能分别查看、隐藏和操作有内容差异的图层。不得以复制整图、增加空层或隐藏原图覆盖合成图的方式伪装拆层。

拆层前后分辨率、图层数、合成差异和可能损失应可见。文字像素层不等于可编辑文字层；不承诺完整恢复原始设计工程。PSD 的真实 Photoshop 验证是本版验收项，不能以导出按钮存在或模拟文件代替。

## 8. 任务预设

提供商品图、海报图、宣传图、插画图、写实图片、图标／小元素、背景图、局部修图八类起步入口。预设改变引导和默认创作描述，不增加八套独立页面。

涉及局部修图的预设要求选择原图；没有图片时先进入选图，不直接发起请求。

## 9. 交互、存储与隔离原则

中文界面、草稿自动保存、耗时操作可见状态、错误保留输入、不覆盖原图。

业务状态本地持久化；外部模型请求按用户配置发送。未经选择的招标资料不得随请求上传。提示词与图片不进入普通运维埋点；密钥不进入前端、日志或导出文件。

人工审核体现在优化结果应用、拆层结果确认及正式对外使用前的人工检查，不为通用生图强行加入招标审批流程。内容来源、用户应用行为、生成与导出留有本地记录。

## 10. 总体验收

| 维度 | 通过条件 |

| 提示词 | 中文参考、更新、个人保存、优化对比、常用风格可用 |

## 11. 阶段规则

需求已确认不等于高保真设计已确认，也不等于允许 Codex直接编写整版功能。

先按配套任务书完成本地基线与技术计划；能力风险和代表性设计获得确认后，按最小可验证功能逐步实现。执行状态只写入仓库既有 `tasks/todo.md`，不建立另一份进度总账。

未经用户另行明确授权，不创建分支、提交、推送、合并、打标签、发布，不修改软件更新、签名或部署流程。

## 12. 一句话总结

生图模式把中文需求、参考图、提示词复用、图片修改和分层交付串成独立流程，减少跨工具复制及重复输入，并降低误覆盖和伪分层交付风险；具体节省时间以试用前后实测为准。
