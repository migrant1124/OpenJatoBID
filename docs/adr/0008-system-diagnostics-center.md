# ADR-0008：系统诊断中心

## 状态

proposed

## 日期

2026-07-15

## 决策人或责任域

客户端运维体验

## 背景

本地组件与更新问题需要用户可理解、支持人员可核验的诊断信息。

## 决策

提供只读的系统诊断中心，聚合版本、更新、渲染、队列和环境状态。

## 不变量

- 诊断不展示 API Key、正文或本地文件路径。

## 备选方案

- 仅查看日志：用户不可自助判断，不采用。

## 正面影响

- 支持问题更易复现和定位。

## 负面影响

- 需要维护脱敏字段。

## 安全与隐私

仅展示允许公开给当前用户的本机指标。

## 运维与回退

诊断中心失效不影响核心工作流。
