# ADR-0010：用户手册自动化

## 状态

proposed

## 日期

2026-07-15

## 决策人或责任域

产品文档

## 背景

手册需要与 Jato 客户端实际界面、版本和发布流程保持一致。

## 决策

以 Jato 专用 Skill 生成或更新手册，并优先 Dry Run 审核计划和截图清单。

## 不变量

- 手册不能混用上游品牌或未验证截图。

## 备选方案

- 纯人工散落维护：难以保证可追溯性。

## 正面影响

- 手册更新有一致的输入、审核和产物路径。

## 负面影响

- 需要维护 Skill 的版本与依赖。

## 安全与隐私

手册不收集用户业务文件或凭据。

## 运维与回退

Dry Run 不写入产物；已发布手册通过版本控制回退。
