# ADR-0009：外部模型发布门禁

## 状态

proposed

## 日期

2026-07-15

## 决策人或责任域

发布工程

## 背景

本地模拟无法证明真实模型的结构化输出兼容性。

## 决策

正式发布前使用密钥注入的受控工作流执行外部模型门禁，记录脱敏报告。

## 不变量

- 不在仓库、日志或产物中存储 API Key。

## 备选方案

- 永久跳过真实验证：发布风险不可接受。

## 正面影响

- 提前发现真实服务兼容问题。

## 负面影响

- 依赖外部服务可用性和人工审批。

## 安全与隐私

密钥仅来自 GitHub Actions Secret，日志严格脱敏。

## 运维与回退

门禁失败阻止发布；紧急绕过需要单独记录并发布更高修复版本。
