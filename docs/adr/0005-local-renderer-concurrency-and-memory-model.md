# ADR-0005：本地渲染器并发与内存模型

## 状态

accepted

## 日期

2026-07-15

## 决策人或责任域

Electron 本地渲染

## 背景

Mermaid、HTML 和超长图需要在本地稳定渲染，同时需要让资源成本可见、可诊断。

## 决策

本地渲染默认并发为 5、最大并发为 20。每个活动任务创建一个隐藏 `BrowserWindow`。超长图采用分段截图，最终以 `width × height × 4` 连续 RGBA 位图内存拼接。

## 不变量

- 不进行内存自适应降并发。
- 不增加像素或高度硬限制。
- 成功、失败、暂停和超时后都清理窗口与调试器。
- 通过诊断、日志和压力测试管理资源风险。

## 备选方案

- 共享单窗口：会造成任务互相污染。
- 自动降低并发或硬性裁剪长图：会改变用户已配置的行为。

## 正面影响

- 并发契约明确，长图输出完整。

## 负面影响

- 超大图片可能申请较大的连续内存。

## 安全与隐私

渲染窗口禁用外部导航与不受控 Node 能力，仅处理本地受控内容。

## 运维与回退

可在设置中将并发调低至 1；诊断中心记录队列、窗口和位图估算。
