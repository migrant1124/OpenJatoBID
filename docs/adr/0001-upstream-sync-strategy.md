# ADR-0001：上游同步策略

## 状态

accepted

## 日期

2026-07-15

## 决策人或责任域

仓库维护

## 背景

Jato Fork 需要持续关注上游，但全量合并会覆盖本地产品边界。

## 决策

通过 Manifest 和只读差异审计识别候选能力；仅在评审后做语义级合并。

## 不变量

- 不自动 merge 或批量 cherry-pick 上游提交。
- 受保护路径命中必须人工审查。

## 备选方案

- 全量 merge：会扩大冲突和产品回归风险，因此不采用。

## 正面影响

- 可追踪每项上游能力的采用状态。

## 负面影响

- 同步需要额外评审时间。

## 安全与隐私

审计只读取 Git 元数据和路径，不上传工作区内容。

## 运维与回退

审计脚本不修改引用；语义合并可通过常规 Git 提交回退。
