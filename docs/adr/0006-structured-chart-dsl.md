# ADR-0006：结构化图表 DSL

## 状态

proposed

## 日期

2026-07-15

## 决策人或责任域

内容生成与图表渲染

## 背景

模型生成任意 HTML 难以验证、渲染和导出。

## 决策

新图表使用带版本的 JSON DSL，并在渲染前校验。

## 不变量

- 不接受新生成的任意 HTML 图表。

## 备选方案

- 继续使用 HTML：安全和兼容边界不足。

## 正面影响

- 图表可验证、可测试并可跨端导出。

## 负面影响

- 首期支持的图表种类有限。

## 安全与隐私

DSL 只允许白名单字段和样式。

## 运维与回退

验证失败时显示可读错误，不写入业务正文。
