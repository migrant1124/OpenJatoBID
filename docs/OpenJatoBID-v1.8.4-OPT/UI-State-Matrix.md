# 全业务流程页面与状态矩阵

适用：v1.8.4-OPT，修订OPT-D1。所有编号均为设计/验收状态，不代表生产功能已完成。

本矩阵包含76个状态：管理端13个、客户端63个。C00仅为首页入口衔接示意，不是首页改稿。所有其他状态提供独立参考PNG；复用弹窗仍单独编号，不能当作独立新增一级页面。

## 主链与分支

管理端：A01 → A02 → A03 → A04 → A01/A05；审计A06/A07，设置A08/A09，发布A10，申请A11，清理A12；已启用来源手动检查A13。

整套制作：C00 → C01 →（资料C02–C04、技能C05–C09及C62、模板C10–C13可选）→ C15 → C16 → C17 → C18（可展开C19）→ C21 → C26 → C27 → C36 → C37 → C38 → C39。

单页制作：C00 → C01/C14 → 在当前会话补齐必要阶段1信息 → C20 → C21 → C26 → C28 → C36–C39。没有独立大纲页面；C20不是把默认确认门禁全部跳过。

等待/失败恢复：C22/C23/C24/C25/C46/C49/C51/C60均回到原任务或可验证检查点；不会创建第二条脱节会话。

扩展输入：C41/C42原生PPT；C43保留原文美化；C44图片重建；C45模板创建能力分流。它们不是新的首页模式栏；按意图路由，缺能力时说明。

工作区辅助：C29–C35、C55–C59及C61保留既有编辑/讲稿/批注/恢复/模板/存储功能；支持C50离开保护、C52确认失效。

## 跨状态补充：不能从示意箭头误读实际业务

原型中的“查看示例完成状态”只便于切换画面；生产程序必须等待真实任务事件自动变化，不出现该按钮。任何通过图稿前进/后退都不代表数据库已更新。

C03/C12/C17/C21/C38中的下一状态由真实任务结果决定，失败分别进入C04/C60/C24/C40。C26根据实际creationScope进入C27或C28。C47首次落盘确认完成后返回原先被挂起的发送/导入动作，而不是固定处理附件。

C07缺依赖时“确认安装”仅针对可安装候选，绝不能启用缺依赖执行。C08–C09被拒绝/获取失败在同一申请查看层呈现；审批后回C07确认安装，不自动启用。

C13还必须提供“按项目画幅重新布局”和“取消”分支；C23/C50/C52/C57/C58确认有取消返回；取消不写文件、不改确认记录。A03新增停用及正在执行的影响根据真实草稿列出，不只显示新增来源。

资源管理的运行记录、只读周计划和技术详情是同一个按钮进入的查看层。PPT用户稿件历史与资源发布历史是不同功能，不得混删。

## 页面完整性验收

Codex以本矩阵逐项登记已实现/沿用已验证/待补齐/阻塞，并分别关联实际源码与截图。不得把一个通用成功页重复登记为所有异常态已验收。真实数据无法达到的状态用可控fixture在测试环境触发，测试证据注明fixture；Windows完整闭环仍需要真实运行。
