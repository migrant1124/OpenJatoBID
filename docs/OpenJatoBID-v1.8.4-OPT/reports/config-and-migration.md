# 配置、迁移与仅撤本轮方案

应用/依赖版本保持不变。管理端默认监听0.0.0.0:47821；本机客户端填127.0.0.1，其他局域网客户端填管理端真实LAN地址。两端独立appId、进程、userData，资源网络设置仅公共资源获取使用，授权/统计继续LAN。测试使用独立目录和临时端口，未改正式配置。

管理端schema 6为加法迁移：资源选择revision、幂等操作及持久任务。默认来源FIFO=1、文件准备<=2。WEEK_MS=604800000，周锚点持久；手动检查/失败重试/重新启用不移动锚点，跨多周只补一次。在途相同来源不重入；running在重开时回queued，取消不恢复。迁移前备份与失败恢复沿用既有databaseService，不降低schema。

客户端新增ppt_conversations/ppt_messages/ppt_questions；草稿、当前有效附件、选择、问答、完整消息及可核检查点进入既有SQLite。旧报告只标历史任务摘要，不补造不存在的聊天。ready资料只能由真实解析和候选提交产生；移除仅解除引用，用户原件保留。源文件、稳定ID、revision/hash、写锁、candidate、commit journal与历史保留。取消/失败不应用候选，检查点按当前内容指纹恢复，不恢复丢失token或自动重发收费请求。

后台新旧稿准备分两次同会话任务：先确认当前ready附件及真实结构/画幅，宿主准备完成后继续原生scope或美化两阶段。Brand/Style/Layout/Deck仅项目内工作区，固定素材读取不赋予外部Skill执行权限。素材白名单PNG/JPEG/WebP/GIF，真实格式对应文件名，来源realpath位于当前有效范围或固定技能templates子树。

审阅与导出不预先勾选。用户明确确认后复用既有confirm保存revision，源修改使确认失效。最新导出结果从当前revision最新completed导出作业的真实回执及存在的文件取得，失败/运行中不显示新成功；复用既有openFile桥接打开文件或目录。

仅撤本轮时：先正常退出测试/正式两端并备份真实userData、管理库、资源镜像及PPT项目含history；核对preflight及本轮文件清单。逐文件反向应用本轮尚未暂存差异，原用户107个暂存交接文件和已提交精简/Pi/资源成果不动，不用reset/checkout/clean/stash。删除本轮新源码前确认没有用户叠加修改；保留新表和数据或使用完整已验证备份，禁止降低schema后继续写新库。新功能已使用后的会话/任务表可以留在数据库中，旧版不得把它们清空。PPT业务恢复使用现有项目历史/归属验证，不整库回退精简成果。

上述只是可检查回退方案，本轮未执行回退、Git写入、真实库迁移或生产目录清理。数据迁移用隔离副本/测试数据库，独立Windows安装升级仍BLOCKED。
