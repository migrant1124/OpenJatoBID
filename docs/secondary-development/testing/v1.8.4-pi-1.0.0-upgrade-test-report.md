## 失败、修复与环境问题

1. **既有失败**：technicalPlanExport.test.cjs:48、:61 两项均 `Missing expected exception`，与精简报告改前/改后90/92中记录相同；实现和测试不在本轮修改范围。Node26的额外14个SQLite ABI失败通过使用兼容Electron Node145消除，没有为测试反向重建并破坏Main环境。
2. **本轮早期测试缺陷**：合成Key含中文使HTTP Header ByteString报错；压缩夹具未真实达到阈值、沿用错误事件名、摘要system检测/分片摘要处理错误；coordinator回调曾把问题正文字符串当对象；历史Store错误使用id而非threadId。已修正夹具并保留失败日志，不当作产品通过证据。最早挂起试验曾由主代理只终止本轮测试进程，最终脚本有单例/总超时及退出码。
3. **真实适配遗漏**：受约束read遗漏图片MIME operation，真实PNG读取失败；已补公开检测接口并保留原路径防护，T14/15重测通过。不能证明此问题由新版引入。
4. **独立审查修复**：压缩成功原断言无法证明工具事实保留，已强化；runtime曾丢压缩失败详情，已保留安全诊断；close提前返回的真实反例 `close-before.log` 退出1，`runtime-review-fix.log` 两例通过，最新29/29及Main/包内重复验证通过。
5. **包内测试入口修复**：首测CJS require.resolve不能解析import-only exports；第二次资源根只读赋值未生效；第三次简化App缺once。均为外置验证入口问题，改用公开findPackageJSON、显式资源属性及真实App方法转发，最终包内完整通过；没有改生产授权/构建配置。三个初测失败日志保留。
6. **审计/构建警告**：40项既有漏洞仍在；Vite既有chunk警告；builder重复依赖引用和Node DEP0190警告。构建实际退出0，警告不掩盖漏洞和未执行验收。本地包没有正式发布/签名验收。
