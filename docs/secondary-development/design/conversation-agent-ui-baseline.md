# Jato Agent 对话工作台 UI 基线

- 一级入口“对话模式”位于“标书生成”和“模板设置”之间，无二级菜单。
- 页面标题“对话智能体工作台”，副标题“通过多轮对话生成内容、整理方案并导出 Word”。
- 主体只有会话列表与聊天区两列；无右侧栏、模式标签、模型名称和推理内容。
- Assistant 统一显示“Jato Agent”，Markdown 禁止 raw HTML。
- 每条回答末尾使用带 Tooltip 和 `aria-label` 的继续扩写、精简润色、改正式语气、导出 Word 图标。
- 复制回答与重新生成收纳在每条回答的更多菜单，不覆盖原回答。
- 输入区支持附件、字符计数、Enter 发送、Shift+Enter 换行和停止；10001 个用户可见字符触发完整文本 TXT 转换，成功后不自动发送。
- 大屏双栏，中屏会话栏可折叠，小屏会话列表使用抽屉；页面与消息卡内部滚动，不产生页面横向溢出。
