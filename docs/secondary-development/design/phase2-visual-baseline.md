## 当前视觉负债扫描

扫描 `client/src/styles/` 的 15 个 CSS 文件：

- 130 处渐变。
- 101 处 `999px` 胶囊圆角。
- 378 处十六进制颜色字面量。
- 153 处阴影声明。

这些数值只用于识别迁移范围，不要求机械清零。状态圆点、头像、胶囊标签等语义上需要圆形的元素可以保留 `999px`；装饰性渐变、超大卡片圆角和高强度彩色阴影需要移除。

## 关键页面回归清单

固定视口：1440×900、1920×1080；启动登录页额外检查 1280×720。

1. 主壳：展开/收起侧栏、菜单选中态、设置入口、浮动工具条。
2. 启动授权：登录表单、授权申请弹窗、错误/等待/批准/拒绝状态。
3. 模型设置：文本模型、生图模型、下拉菜单、API Key 获取按钮、测试状态。
4. 关于：版本卡片、隐私声明 01—04、长文本滚动。
5. 技术方案：Step01—04、Markdown/Mermaid、生成进度和导出工具条。
6. 知识库、查重、废标检查、资源、导出模板和开发者页面。

## 验收方式

- 每完成一组页面，按固定视口保存截图并与本清单核对。
- 只允许视觉外观和必要的响应式修复，不移动菜单、步骤、业务按钮或内容分区。
- 使用键盘 Tab 检查所有交互控件，焦点环必须可见。
- 构建命令：`cd client; npm run build`。
