## 使用与迁移

管理端先登录/首次改密，在资源中心启用已批准来源并选择资源目录、网络与配额；周期只读固定一周，手动检查不移锚点。资源准备成功后签名发布；失败审计可重试，旧快照继续可用。员工通过现有LAN授权登录，目录后台同步，首次建立基线；已有变化在安全时机显示两中心概括，查看进入对应筛选，可从更新记录回看。

PPT新建项目选择独立父目录，系统卷按真实卷GUID提醒，可明确仍然使用。添加资料/原PPT，选择真实模板路线或明确Quick；Default核对需求与页面计划并确认当前修订，制作候选通过检查后保存为待人工审阅。元素/图表/讲稿修改、局部Agent、历史恢复、导出均检查修订与互斥。视频需明确启用并导入已获授权本地音频。技能安装确认用途、依赖、许可与权限；安装不等于执行。项目/技能/缓存迁移复制校验后切索引，旧目录保留；失联不另建系统盘副本。删除只回收归属项目子目录，恢复需从回收站恢复完整目录再核验归属和页面hash。

SQLite只新增表/字段并沿用原备份迁移；不降低授权库校验。七源旧线路只读归档，个人收藏/译文/副本/启停/删除记录保留，旧seed不重新覆盖。两软件版本不同不影响既有授权，资源协议不兼容保留旧缓存与业务。
