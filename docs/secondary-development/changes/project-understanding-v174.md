## 九步实施结果

1. 核对真实链路：目录由 `outlineGenerationTask` 生成并经 `technicalPlanStore` 落 SQLite；正文统一走 `contentGenerationTask`；Word 统一走 `exportService`。确认自然拆分规则仍由 `outlineNaturalGrouping.cjs` 提供，Agent 工作区网络权限未变。
2. 最小契约：SQLite schema 升至 v25，仅追加 `project_understanding_json`；其中保存位置计划、研究版本、来源、证据、关联、缺口、审核及审计记录。合成夹具不含真实项目或个人数据。
3. 位置识别：复用真实“项目理解/认识”分析节点，避免把“项目概况”误认；只在可编辑的既有方案父节点中补全，不新增根章节，不移动既有子目录；用户删除后记录 `excluded`。
4. 公开研究：Main 侧新增 Brave Search API 调用、授权知识库材料和公开 HTTPS 页面/PDF 正文获取；DNS 固定与重定向复核、2MB 流式上限、GBK/UTF-8、超时、重试、取消、敏感查询、同输入缓存及公开/内部来源预算均已接入。搜索摘要只发现链接，不作证据；Agent 联网边界未改变。
5. 证据核验：AI 只能返回来源正文中逐字存在的片段；程序再次核对片段、截止日期、讲话属性、文号、适用性和有效性。关联不按层级顺序自动生成；direct 关系还必须提供逐字关系片段、匹配类型的关系词和同段双端点证明，background/inference 只能按其性质写作。缺少宏观/行业—上级/采购人—项目/响应链时保留阻断缺口。`.gov.cn` 标为政府官方域名并优先，其他域名进入显式人工确认范围。
6. 专用写作：仅对 `feature_role=project-understanding` 子树注入证据及已校验关系候选包；复用 `outlineNaturalGrouping.cjs`，只有多个独立、非事实型主题才拆分，否则保留叶子。所有正文落盘统一执行 `〔PU:evidence_id〕` 守恒，覆盖首次生成、单节/整本重生成、普通/Agent 修复、原方案回写、扩写、字数调整和去表格后处理，其他章节文风不变。
7. 无损应用：正文页复用现有 Step 05，显示截止日期、研究主题、来源、证据、已核验关系、缺口、审核状态和新旧来源差异；刷新形成待应用版本，不静默改正文。人工确认只接受带 `[可人工确认]` 的缺口，阻断缺口仍保持 partial/待复核；成功、失败、取消和 Word 导出结果均写轻量审计记录。
8. Word 引用：整本导出及正文页“导出当前小节 Word”都按各自实际引用重新生成 `〔PU-n〕`，跨叶子去重并只在导出范围末尾附一次参考依据和链接；内部 source_id 不进入 Word。无研究版本、阻断缺口、内容审核未通过或人工审核未绑定当前版本时，文件名及正文标为待复核，不恢复旧整本证明材料硬门禁。
9. 回归交付：新增位置、关系、引用保留、HTML 编码、网络边界、预算取消、人工审核、配置、SQLite 与真实 DOCX 包回归；完成相关旧回归和客户端构建。分层结果见 `docs/secondary-development/test-reports/project-understanding-v174-test-report.md`。

## 配置说明

入口：`设置 > 组件设置 > 公开资料检索`。

| 配置 | 默认值 | 范围/说明 |
| --- | ---: | --- |
| Brave Search API Key | 空 | 只保存在客户端本机配置，只有 Main 侧研究服务使用 |
| 每主题候选数 | 5 | 1–20 |
| 最多来源数 | 8 | 1–20 |
| 单请求超时 | 20000 ms | 5000–60000 ms |
| 整体任务预算 | 300000 ms | 60000–900000 ms |

需要用户完成的唯一外部动作：在 Brave Search API 控制台创建可用订阅并取得 API Key，然后填入上述设置。账户、付款方式、额度和费用由用户自行确认；程序不会代开账户或购买服务。没有 Key 时，位置、存储、写作、引用和导出等离线部分仍可使用和测试，但真实研究会明确提示未配置。

整体预算和用户取消把同一个 `AbortSignal` 传入模型 HTTP、JSON 修复和重试链；取消会中止正在执行的传输、停止后续重试并阻止旧结果写回。

## 保护与回滚

- 查询只接受用户人工确认的公开主题，拒绝密钥、密码、证件号、手机号、本地路径和 `file://`；正文抓取仅允许 DNS 校验后的公开 HTTPS 地址。
- 研究结果绑定目录修订摘要；目录在任务期间变化时拒绝旧结果写回。新资料先成为待应用版本，人工正文、图片、附件和当前正文不会被自动替换。
- 回滚本增量时可停用研究入口并忽略追加的 JSON 字段；SQLite 追加列不要求旧项目回填。历史正文和前两轮自然拆分/正文优化不得回退。
