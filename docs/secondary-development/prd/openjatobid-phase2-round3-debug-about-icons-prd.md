# OpenJatoBID 第二阶段第三轮优化 PRD：调试入口、关于页与桌面图标

版本：1.0  
日期：2026-07-11  
适用产品：`Jato AI BID` 员工客户端、`Jato AI BID 管理端`  
需求基线：`openjatobid-phase2-ui-lan-management-prd.md`

## 1. 背景与问题

第二阶段功能已经形成员工客户端与管理端两个独立 Electron 软件，但本轮验收发现以下问题：

1. 员工客户端直接访问 Vite 页面时长期停留在“正在读取本机授权…”，无法检查登录页；Electron 开发模式又默认跳过局域网授权，无法从登录页开始调试。
2. 管理端直接访问 Vite 页面时提示桌面桥接不可用，无法用浏览器检查界面细节。
3. 客户端“关于”页缺少当前登录员工信息和明确的退出登录入口。
4. 隐私声明四个条目在宽屏下以三列换行，卡片长短失衡、留白明显。
5. 客户端 Windows 任务栏身份未显式绑定应用 ID；管理端托盘使用临时 SVG，而不是公司 Logo，存在默认图标或空白图标问题。

## 2. 本轮目标

- 为两端提供清晰、可重复的浏览器 UI 调试入口，不再被 Electron preload 缺失阻断。
- 为客户端提供强制经过真实局域网授权门禁的 Electron 调试命令。
- 在客户端“关于”页增加“登录账号”卡片，显示用户名、授权期限和退出登录按钮。
- 将隐私声明 01—04 在宽屏下横向四列展示，并为中小视口提供稳定降级。
- 统一客户端任务栏、管理端主窗口和管理端托盘的公司 Logo。

## 3. 范围与产品规则

### 3.1 员工客户端调试

- 浏览器直接访问 `http://127.0.0.1:5173` 时展示员工登录页，不再显示无限加载状态。
- 浏览器预览是仅开发环境生效的 UI 预览，不伪造生产授权、不写入业务数据，也不替代 Electron 验收。
- 浏览器可通过 `?preview=about` 直接预览带模拟账号信息的“关于”页。
- Electron 授权调试命令必须设置 `YIBIAO_REQUIRE_LAN_LICENSE=1`，从员工登录页开始并使用真实 preload、授权服务和局域网请求。

### 3.2 管理端调试

- 浏览器直接访问 `http://127.0.0.1:5174` 时安装仅开发环境使用的内存桥接，展示管理端登录页。
- 浏览器调试账号只用于进入 UI 预览，任意非空用户名和密码均可登录；所有数据仅在页面内存中保存，刷新后重置。
- Electron 开发和正式构建继续使用真实 preload、SQLite、管理员认证和局域网服务；浏览器内存桥接不得进入生产分支判断。

### 3.3 关于页登录账号

- “登录账号”与“自动更新”“软件信息”并列为三个一级卡片。
- 展示字段：用户名（员工姓名）、授权期限、授权状态。
- “退出登录”只清除当前 Renderer 会话并返回员工登录页，不删除本机授权、不撤销设备、不向管理端发起撤销请求。
- 员工再次输入姓名和手机号后可使用当前仍有效的本机授权登录。

### 3.4 隐私声明布局

- 宽屏：01、02、03、04 四个条目横向四列、顶部对齐。
- 中等视口：两列。
- 小视口：单列。
- 不修改已批准的隐私声明正文。

### 3.5 桌面图标

- 客户端在 Windows 上设置稳定的 AppUserModelID，与打包 `appId` 一致。
- 管理端主窗口与托盘均读取 `management/assets/icon.ico`，不再生成临时 SVG。
- 管理端构建必须包含运行时图标文件，并设置与打包 `appId` 一致的 AppUserModelID。

## 4. 非目标

- 不重做两端登录业务、注册体系、管理员密码规则或授权审批逻辑。
- 不为浏览器预览实现完整 Electron、文件系统、SQLite 或局域网服务模拟。
- 不改变员工设备授权记录、30 天校验规则或每人 3 台设备上限。
- 不修改关于页以外的现有页面布局。

## 5. 验收标准

1. `npm run dev:browser` 启动客户端后，浏览器打开 5173 直接看到员工登录页；控制台无导致页面中断的桥接错误。
2. 客户端打开 `http://127.0.0.1:5173/?preview=about` 可检查完整关于页和模拟登录账号卡片。
3. `npm run dev:licensed` 启动客户端 Electron 后从员工登录页开始，真实授权链路可用。
4. `npm run dev:browser` 启动管理端后，浏览器打开 5174 显示管理员登录页，非空账号密码可进入管理界面。
5. 两端 `npm run dev:inspect` 可分别通过 9222、9223 远程调试真实 Electron Renderer。
6. 关于页三个一级卡片并列；账号卡片显示姓名、授权期限和退出登录。退出后回到登录页，本机授权未被删除或撤销。
7. 隐私声明在宽屏为四列、中屏两列、小屏一列。
8. 客户端任务栏和管理端主窗口/托盘均显示公司 Logo；管理端打包文件包含 `assets/icon.ico`。
9. 客户端和管理端 TypeScript/Vite 构建通过；修改的 Electron CJS 文件通过 `node --check`。

## 6. 交付物

- 本 PRD。
- 两端浏览器与 Electron 调试脚本。
- 客户端浏览器预览入口、关于页账号卡片与退出登录状态流。
- 管理端开发内存桥接。
- 两端 Windows 应用身份和管理端托盘图标修复。
- 构建、运行与截图验证记录。
