# 第二阶段员工用户端使用说明

## 登录与申请的区别

启动页用于已经获批的员工登录。已授权员工只输入姓名和手机号，软件自动识别当前设备；姓名、手机号和当前设备必须与管理端授权一致。

新员工或新电脑在启动页左下角点击“授权申请”，在独立弹窗中填写：

1. 员工真实姓名；
2. 11 位手机号；
3. 管理员提供的局域网服务器 IP，例如 `192.168.1.10`。非默认端口可填写 `192.168.1.10:端口`。

提交后可在弹窗中等待自动刷新或手动刷新。管理员批准后关闭弹窗，返回启动页输入姓名和手机号登录。

## 授权规则

- 每名员工最多同时绑定 3 台有效电脑，每台新电脑都要单独申请和审批。
- 单次授权有效期为 1 年，管理员可以续期、拒绝或撤销。
- 授权保存在当前电脑，本地离线可以继续使用；但至少每 30 天必须连接一次局域网管理端完成校验。
- 管理员撤销后，客户端下次连接管理端时立即暂停使用；超过 30 天未校验也会暂停使用。
- 更换电脑、系统机器标识变化或管理端身份变化时，需要重新申请或联系管理员。

## 常见提示

| 提示 | 处理方式 |
| --- | --- |
| 无法连接局域网管理端 | 确认电脑已接入公司局域网，检查服务器 IP、端口及服务器防火墙 |
| 有效设备已达上限 | 请管理员撤销不再使用的旧电脑后重新申请 |
| 当前设备授权已被撤销 | 联系管理员确认；需要继续使用时重新申请 |
| 授权已到期 | 请管理员续期或重新申请 |
| 超过 30 天未连接管理端 | 接入公司局域网后重新登录校验 |
| 本地授权与当前设备不匹配 | 为当前电脑重新提交授权申请 |

## 数据边界

用户端不再向 `analytics.agnet.top` 发送授权请求或运维埋点，只连接授权申请中保存的局域网管理端。公告、资源列表和 GitHub 软件更新仍是独立的公共内容能力。业务文档、API Key、方案正文和导出文件不属于运维埋点，不会上传至管理端。
