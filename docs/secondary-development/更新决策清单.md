## 合入注意事项

1. 字数控制相关提交改动集中在技术方案正文生成链路，合入前应重点验证目录生成、正文生成、扩写/缩写、暂停/恢复、失败重试和导出前内容一致性。
2. Pi Agent 提交新增依赖和 runtime 抽象，可能与二开项目现有 OpenCode Agent 隔离方案、统计逻辑和配置页存在冲突。
3. 插件系统涉及客户端、Analytics Worker、Dashboard 和数据库迁移，建议不要混入其他功能一起合入。
4. 样式提交 `45ed082` 影响面较广，如果二开项目已有管理端或客户端 UI 改造，应单独 diff 后再决定。
5. 文档和徽章类提交可以最后处理，避免增加功能合入时的冲突噪音。
