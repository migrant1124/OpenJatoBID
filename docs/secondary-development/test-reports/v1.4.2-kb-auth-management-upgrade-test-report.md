## 2. 实现结果

### 2.1 知识库重命名和查看页

- 用受控 Radix Dialog 替换 `window.prompt`，支持默认值选中、Enter 提交、Esc/取消、空值/同名/重复提交保护。
- IPC 返回空值或失败时保留输入；成功后立即刷新当前名称。
- Viewer Header 拆为“知识库 / 文件名 / 条目数 / 返回知识库 / 模式与开发者操作”五个语义区。
- 补充长中文、长英文文件名换行，以及 `>1100px`、`860–1100px`、`<860px` 三档布局。

### 2.2 稳定 Device Code 和 Bootstrap

- 新设备码版本固定为 `jato-device-v1`，由 appId、平台和稳定操作系统机器标识生成，不依赖 Client ID、MAC、主机名或客户端版本。
- 新 License 优先验证 Device Code；旧 License 继续兼容 Fingerprint。
- 新旧客户端申请和登录可同时携带 Device Code 与旧标识，唯一匹配时回填 Device Code；歧义候选拒绝自动绑定。
- Windows Bootstrap 固定在 `%LOCALAPPDATA%\JatoDigital\OpenJatoBID\bootstrap.json`，只保存管理端地址、公钥信任、Schema 和更新时间。
- 删除 `user_config.json` 与 `license.json` 后，仍可从 Bootstrap 恢复连接并为原设备重新签发 License；Bootstrap 缺失时允许手工恢复管理端地址。
- Bootstrap 与用户配置的公钥冲突时拒绝替换信任。

### 2.3 统计、设备归一化和三台上限

- 管理端分别返回申请记录、待审批、员工数、唯一有效设备绑定数。
- “员工与设备”区域同时展示员工数与有效设备数，不再用员工数冒充设备数。
- 同一 Device Code 重复审批更新原绑定，不消耗新增额度。
- 明确的旧记录重复组按稳定非空 Client ID 或相同旧 Fingerprint 合并；无证据或歧义候选不合并。
- 审批前先归一化历史重复，再按三台唯一绑定检查额度；第三台可批准，第四台返回 `DEVICE_LIMIT`。
- 无 Device Code 的旧客户端在 Fingerprint 变化但稳定 Client ID 匹配时继续授权。

### 2.4 撤销状态机

- 撤销事务创建内部墓碑、使 License 失效、删除普通设备绑定并立即释放额度；普通 UI 不显示墓碑。
- 客户端使用 Bearer Watch Token 订阅 SSE，撤销事件不把凭据放入 URL。
- 撤销在客户端先落盘并通知 Renderer，ACK 为后台 best-effort，不会因 ACK 卡住而延迟退出授权。
- 订阅建立前已提交的撤销可在晚订阅后立即收到；断线重连前先主动校验，30 分钟校验仅作为兜底。
- 在线与离线命中 `REVOKED`/`NOT_AUTHORIZED` 后均持久化失效状态，不再回退到旧离线授权。
- 墓碑保留 30 天，客户端确认后可提前清理；长期未上线时按期限清理墓碑和许可残留。

### 2.5 管理端数据和管理员升级保护

- Windows 数据目录固定为 `%LOCALAPPDATA%\JatoDigital\OpenJatoBID-Management\management.sqlite3`，不依赖 Electron 产品名或版本对应的 `userData`。
- 旧数据库通过 SQLite backup 复制到固定目录并执行完整性检查；复制失败删除不完整目标并保留旧数据库。
- 每次 Schema 迁移前创建并验证真实文件备份；迁移失败恢复原库，不创建空管理员账号。
- `OWNER`、`INITIAL_PASSWORD_REQUIRED`、`LEGACY` 三类管理员状态均保留既有凭据；LEGACY 只补齐确定用户名，不替换 Hash/Salt。
- 安装包初始凭据只允许初始化全新数据库。已有业务数据库缺少 `admin_auth` 时明确失败，业务服务在管理员所有权校验前不会写入签名或授权数据。
- 管理端 `package.json` 的 `name`、`appId`、`productName` 和版本未修改。

## 6. 未完成或需人工授权的验收

以下项目没有被自动化结果替代：

1. 使用**当前代码新生成的管理端安装包**执行实体覆盖安装，并用原管理员账号登录；
2. 卸载/重装管理端后再次使用原管理员账号登录；
3. 在真实双端 Electron 客户端中点击知识库重命名，人工确认 Enter、Esc 和失败后输入保留；
4. 在真实管理端与员工客户端联机状态下执行一次在线撤销，人工确认客户端立即返回授权页。

本轮未获得安装、卸载或改写真实管理端用户数据的授权，故没有执行前两项。当前结论是“代码实现和本地验证通过，可进入实体安装验收”，不是“v1.4.2 完整发布验收通过”。
