# OpenJatoBID 二开测试报告目录

本目录用于保存 OpenJatoBID 二次开发相关测试报告。

测试报告按二开阶段归档。第一阶段报告覆盖品牌重塑，第二阶段报告覆盖 Ant v6 视觉、局域网授权、独立管理端和局域网统计。

第一阶段测试报告应覆盖：

- 品牌残留扫描结果
- Electron 安装包与系统识别验证
- Logo、`.ico`、`.icns` 显示验证
- 导航入口隐藏与保留验证
- 主流程回归验证：上传招标文件 -> 解析 -> 目录 -> 全局事实 -> 正文 -> 导出 Word

建议文件命名：

`YYYY-MM-DD-phase1-branding-test-report.md`
