# OpenJatoBID v1.8.2 验收标准与测试用例

状态说明：本文件是待实施测试清单，不表示 OpenJatoBID 已完成这些功能。真实模型、国内网络、Windows 安装等测试本次未执行。静态图稿检查另见 `交付检查记录.md`。

## 必须满足的总标准

原有反推不丢失；优化唯一且放在模型之后；仅六个批准项；模型说明有官网来源；本地风险预评估真正撤除且不损坏输入/幂等/服务方限制；优化默认至多一次模型请求；知识每周/手动/离线可更新；个人库和密钥受保护。

每个测试在实施报告填“通过/失败/未执行/环境待核实”，附日期、分支/SHA、操作证据或自动化日志。不得以本规格有测试条目代替执行。

## 性能报告格式

同一组条件记录机器、系统、网络、当前模型/中转、输入字符/token、图数量/字节、知识版本、冷热缓存、并发负载；每个分组记录不少于预先约定的样本量和 P50/P95。

拆分：界面反馈、排队、本地检索、图片预处理、HTTP发出、首个可见文字、最终完成、校验。单独统计失败/中断/超时，不从样本里悄悄剔除。

500ms 检索预算不包含模型读取新增知识的耗时；加入知识前后端到端增量必须另测。

## 质量评分记录

建议同一组30条需求由至少两名实际使用人员盲评：原意与约束保留、参考图角色、画面执行描述、无关信息、可读性、需要人工修改量。分歧保留，不宣布任一模型“全场景最好”。

真实模型测试涉及费用，在用户明确额度后执行；不预先填费用与提升百分比。
