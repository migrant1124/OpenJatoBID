## 这些指令在做什么

步骤1避免覆盖现有成果；步骤2把用户选择落实到真实模型路由；步骤3–4把 Skill 变成可更新的本地资料；步骤5–6让优化真正用资料而不增加多轮等待；步骤7保证员工看见的按钮正确；步骤8取消额外风险问答同时保留防重复和输入保护；步骤9–10验证并交付，不擅自发布。
