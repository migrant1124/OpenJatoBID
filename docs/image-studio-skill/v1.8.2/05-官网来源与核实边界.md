# OpenJatoBID v1.8.2 官网来源与核实边界

官网材料核查日期沿用上一交付：2026-09-28。本次文档修订：2026-09-29，目标版本v1.8.2；本轮仅按用户截图更新金龙请求ID和放置说明，未重新抓取官网或发起真实模型测试。模型优缺点来源维持原说明；用户截图仅用于渠道型号字符串确认。

## 重要结论

1. `gpt-image-2`、`gpt-image-2.5-sunburst`、`gpt-image-2.5-flare` 均查到对应 OpenAI 官方模型页。[O1–O4]
2. 对 `gpt-image-2-1k`，本次在 OpenAI 官方站未检索到独立模型页。它仍按用户给定的金龙模型 ID 原样保留；不擅自宣称比普通版更快、更清晰、只支持 1K 或更便宜。
3. 上一交付记录的 Google 官方标识为 Nano Banana Pro：`gemini-3-pro-image`，Nano Banana 2：`gemini-3.1-flash-image`。[G1/G4/G5] **本轮用户截图已确认金龙实际请求ID分别是 `Nano Banana Pro` 和 `Nano Banana 2`。[U1]** 官方标识仅作资料；金龙请求不得替换为这些 `gemini-*` 名称。截图确认的是ID，不是协议、额度或真实出图能力。
4. 不复用旧图中“Sunburst 更强艺术风格”“Flare 更强光影”“Nano Banana 文字较弱”等没有本次官网依据的说法。按精细编辑、日常速度、复杂视觉和文字等真实定位改写。
5. Google 发布介绍与当前 API 指南中关于人物/物体参考数量存在口径差异。本次 UI 不显示这些上限；应用继续最多 4 张，再与实际中转能力取较小值。不能把官网宣传数量直接写成项目支持数量。
6. 官网比较不等于跨厂商同条件测评，也不等于金龙的速度、收费或可用性承诺。模型与渠道能力分开存储。
7. 本交付未使用用户密钥，没有发起任何收费模型请求；没有测试大陆联网、金龙鉴权、真实生图和软件安装包。
