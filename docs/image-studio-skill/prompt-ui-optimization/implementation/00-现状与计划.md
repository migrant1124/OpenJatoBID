## 静态定位与运行复现

- `ImageStudioCreate.tsx` 当前把优化与反推放在同一个 `.image-studio-dialog`；优化方向是 `select`，案例开关是裸 `checkbox`，正文只显示 `card`，没有案例详情页。
- `feature-image-studio.css` 的 `.image-studio-dialog` 宽度上限 700px、高度上限 780px 且容器 `overflow:auto`；`.image-studio-compare textarea` 只有 `min-height:220px`，没有从对比卡片取得剩余高度。`.image-studio-dialog :is(input, select)` 将 checkbox 也匹配为 `display:block;width:100%`，是放大的直接样式来源。上述为代码证据；实际计算样式和截图仍需运行确认。
- `imageStudioKnowledgeWorker.cjs` 持有完整 `prompt/sourceMedia`，搜索返回时却只给 `card` 和媒体地址；`optimizePrompt()` 中旧库候选也被缩为 450 字符，最终拼接时再截为 360 字符。当前 `sources` 不是实际请求文本的证据。
- 现有优化缓存仅在服务进程内，且缓存结果不含完整案例快照。`loadCover` 已有 HTTPS、公共地址、图片格式及缓存检查，可供已授权案例媒体读取复用。
- 当前 `applyAllowed` 以排除部分状态的方式计算，需核对中断稿和人工修订资格。主输入具有草稿 revision，但优化应用尚未利用跨窗口版本冲突检查。
