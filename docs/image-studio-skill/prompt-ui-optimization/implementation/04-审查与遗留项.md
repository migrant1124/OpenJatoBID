# 审查结论与遗留项

## 独立只读审查及处理

审查发现的顶层确认框焦点、停止竞态、误关人工稿、混合英文误判、跨案例错误串写、发送证据误标、跨窗口翻译取消串扰，已分别修复。旧临时 `useKnowledge` checkbox 和 H02 缩略图预载经规格复核不构成遗漏：已确认 H01 要移除 checkbox，后台仍遵守 YouMind 与各来源的独立启用状态；H02 打开后顶部案例卡需要真实缩略图，H01 未打开 H02 前不加载它们。修复后构建、定向测试和隔离 Electron 操作均重新执行，详见 `03-测试报告.md`。

## 保留的边界与未验收内容

1. **收费模型与真实渠道：**本轮未调用真实文本优化、案例翻译或金龙生图。模型遵守复杂否定、品牌、数量及生成质量尚无实测结论；截图中优化稿来自本地 mock。用户明确禁止本轮收费模型测试。
2. **物理显示与输入：**已经取 1440×900、1280×800、1024×768 及两个等效窄视口的 Electron 截图，未在 Windows 物理 125%/150% DPI 和真实中文输入法下验收。
3. **长稿与异常：**04 清单中长文本/超限、离线媒体、404/格式失败、完整流式 UI、双窗口冲突及晚响应等用例仍标「未执行」，不能用构建通过替代。
4. **人工稿恢复范围：**H01 误关后可点击「恢复上次优化稿」，同一窗口切换标签返回时会按窗口归属从本地 SQLite 取回人工稿。应用成功会清除恢复标记。进程重启后窗口身份可能变化，跨重启恢复尚未验收；不能据同窗口结果宣称跨重启可恢复。
5. **历史缓存：**旧版优化缓存原来只在进程内，重启后不会留下可打开但缺完整快照的旧缓存；本轮没有伪造历史案例全文。未来若持久化旧格式缓存，必须明确显示详情缺失状态。
6. **回退与性能：**v40 升级在隔离库多次启动可用；实际用户数据库的降级演练未做。热详情 50 次 P95 仅代表本机隔离 IPC，不覆盖媒体慢网或翻译模型。
