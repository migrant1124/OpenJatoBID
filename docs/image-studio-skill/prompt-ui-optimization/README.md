## 2. 文件怎么放

ZIP 解压后得到 `prompt-ui-optimization` 文件夹。将**整个文件夹**放入：

```text
D:\Documents\OpenJatobid\docs\image-studio-skill\
```

最后路径应为：

```text
D:\Documents\OpenJatobid\docs\image-studio-skill\prompt-ui-optimization\01-完整优化规格.md
```

不要套成 `prompt-ui-optimization\prompt-ui-optimization`。旧 `docs/image-studio-skill/v1.8.2/` 开发资料可以保留；本轮是独立增量包，不覆盖已发布版本规格。本目录不是 Skill 运行目录，不放进 `.agents/skills`、`node_modules` 或软件安装目录。

意思是：让 Codex 明确读取这次增量规格而非旧发布包，保留已确认界面和现有功能，把开发记录写回同一文件夹。产品代码按项目模块规范修改，不写在 docs 里。

## 5. 哪些图上内容不应硬编码

固定「3条」、模型名、示例文本、`353 / 2000` 都是设计示意；真实计数与模型来自会话，应用上限仍为10,000。四个常用方向优先呈现，旧方向按钮化保留；完整中文不能用摘要代替；案例页应用的是当前案例正文，覆盖前确认，不自动添加图片或生成。
