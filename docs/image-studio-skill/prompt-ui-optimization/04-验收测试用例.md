## 执行规则

每条记录实际环境、输入数据来源、步骤、实测结果、状态与截图/日志。状态仅使用「通过 / 失败 / 未执行 / 阻塞」。真实外部模型或网络未测时不能用 mock 结果替代。付费联调须先取得用户授权。

布局至少覆盖 1440×900、1280×800、1024×768 及 Windows 100%/125%/150% 缩放。两图示例仅作为视觉参考；功能测试使用中性素材与真实来源样本，不把设计图片的提示词硬编码成生产默认。

## 性能对照与证据

固定同一测试环境、模型、输入长度、图片数量和输出范围，分别跑无知识、知识命中、无匹配、超时、详情热缓存、图片慢网络和首次中文翻译。计时从用户点击开始，区分本地准备、队列、首段与总耗时。

建议为不收费的本地检索/热详情至少采样 50 次并报告 P50/P95；外部模型样本量由授权费用决定，少量样本只报告单次值与范围，不冒充稳定的 P95。

核心指标：不开案例时媒体下载/翻译均为0；本次优化改写请求≤1；热详情P95目标≤200ms；检索与快照总等待预算500ms；返回不重复调用模型。时间目标均须实测。
