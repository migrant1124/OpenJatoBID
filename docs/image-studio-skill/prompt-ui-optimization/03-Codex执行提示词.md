## 二、分步任务

下面步骤是一次完整交付的执行顺序，不是产品分期。每步需要检查输出后再继续，不能只写计划就宣称实施完成。

### 步骤 1：复现问题、核对差异

**输入：**当前工作区、开发约束、evidence 原页面截图、固定基线的核查结论。

**操作：**先运行只读 git status/branch/remote 查询，检查当前版本与未提交修改。阅读 ImageStudioCreate、ImageStudioPage、样式、preload、ipc.ts、imageStudioService、Knowledge/Worker 和个人提示词库。运行项目已有非付费检查。复现弹窗并查看计算样式和尺寸，确认大 checkbox、窄长框与 textarea 高度根因。

**输出：**`implementation/00-现状与计划.md`；包含实际代码基线、复现截图、准确文件/符号、既有失败与拟改范围。

**约束：**不根据截图凭空认定 CSS 根因；不回退到本文件的参考提交；不顺手更改模型说明等无关内容。

**退出条件：**能指出真实状态传递、样式冲突和案例数据缺口，而不只是笼统说“UI 有问题”。

### 步骤 2：定义并实现会话/案例快照

**输入：**现有 optimizePrompt、旧参考库条目、YouMind 完整知识行与服务存储。

**操作：**定义父会话、原始输入指纹、原文、完整优化结果、人工稿、来源版本和案例快照。为最终选中至多三条案例保存完整原文、媒体信息、来源与内容哈希。Knowledge Worker 增加按版本/ID获取详情或一次性带回选中条目的能力；旧参考库必须同样支持。

**输出：**局部 store/数据库迁移、类型定义、快照构建函数和单元测试。

**约束：**不在 Main 重复同步解压整库；不让 frontend 直接传 URL 任意下载；签名包保持不可变；迁移幂等，不丢草稿、收藏、作品。权限绑定本窗口会话。

**退出条件：**旧来源和知识包都能从本轮 caseSnapshotId 读出同一版本完整详情；更新或停用来源后不会错换当前案例。

### 步骤 3：记录实际提供给 AI 的内容

**输入：**最终请求体、匹配案例和单次模型调用链。

**操作：**在所有单项/整体截短完成后，记录真正拼进请求的 sentExcerpt、sentContext、顺序和哈希。区分仅组装、已提交请求与历史缓存；排队取消时不得宣称已经提供给模型。把真实案例计数传给 UI。

**输出：**可复核的引用记录、结果缓存快照、上下文一致性测试。

**约束：**不能把 450 字符 card 当成最终已发送的 360 字符片段；不调用新模型写“参考理由”；UI 展示完整中文和图片不代表模型看过它们。

**退出条件：**测试捕获的实际 HTTP messages 中案例文本，和详情页“实际提供”逐字一致；条数与非空真实提交资料一致。

### 步骤 4：实现 H01 宽幅优化对比

**输入：**已确认 H01、Handoff、当前组件/样式、会话状态。

**操作：**拆出专用优化 Dialog，局部类名隔离；移除裸 checkbox，变为案例信息栏；将方向换成同式单选按钮，常用四项优先、原有模式后置换行；新增包装设计/电商主图的后端模式和规则；右编辑区填满、左右等高、页脚固定。

**输出：**H01 组件、scoped CSS、可访问性与尺寸测试、各状态截图。

**约束：**不改反推共用样式；不能删除旧方向；点击方向不自动请求；“停止”仅运行中可用；字数上限保留 10,000。保留图中的两个同名案例入口，共用一个处理函数。

**退出条件：**1440×900、1280×800 以及规定缩放下无小文本框/大空白，无巨大对勾，底部按钮可见且可用。

### 步骤 5：实现 H02 案例图文详情

**输入：**已确认 H02 和本轮快照接口。

**操作：**独立案例 Dialog：顶部卡片切案例、左大图、右完整中文/原文、下实际引用、底部操作。返回时恢复原 H01 会话。案例页关闭、大图关闭分别只回退一层。适配真实 0/1/2/3 条，媒体为空或缺失情况。

**输出：**H02、案例卡、图片/文字阅读组件、返回路径测试。

**约束：**不做内联长列表、不改变主页面布局；不新查一组相似案例冒充本次引用；切换期间晚响应不得写错对象；原文缺失不能用摘要代替。

**退出条件：**可以从本轮实际两种来源各打开真实案例；图文、原文、实际片段和来源身份一致。

### 步骤 6：补齐图片与中文显示

**输入：**caseSnapshotId、当前媒体、原文、来源中文或译文缓存。

**操作：**复用下载缓存和查看器；按当前案例加载真实图。新增独立中文缓存，优先中文全文，缺失时在 H02 阅读区提供“翻译为中文”及费用说明，用户主动点击才用现有 aiService 翻译当前条；重复点击在途合并。

**输出：**可信媒体读取、单条翻译/取消、内容哈希缓存和错误状态。

**约束：**不全库翻译；不带用户私有提示词和参考图进入案例翻译请求；单击最多一次模型请求、不自动修复重试；不把混有汉字的英文误判为完整中文；译文保持变量和原样上屏文字；不伪造案例图。

**退出条件：**打开 H01 不下载案例图也不翻译；H02 已有中文立即读本地；缺中文明确可操作；失败保留原文；缓存复用不重复收费。

### 步骤 7：完善复制、保存、应用和冲突保护

**输入：**页面一优化稿、页面二当前显示语言文本、主创作输入修订号与个人库。

**操作：**分别实现优化稿与案例的动作语义。案例应用前确认将替换创作输入、不添加图片；确认后保留撤销及本轮人工稿快照。复制当前明确显示的全文，保存携带来源/译文标记并避免重复收藏。

**输出：**动作处理函数、输入指纹检查、幂等记录和测试。

**约束：**不把案例文本偷偷写入优化稿；不改变模型和参考图；不自动生成；主输入已经变化则拒绝静默覆盖；超 10,000 字不截断应用；停止或中断稿不能当完成稿。

**退出条件：**每个按钮的对象都能在测试中逐字确认；保存不应用、应用不生图、返回不丢稿、撤销可恢复。

### 步骤 8：完成缓存、生命周期与安全检查

**输入：**在途请求、多个窗口、知识更新、已存在缓存、当前安全约束。

**操作：**处理乱序 chunk、旧请求完成、快速切案例、返回/关闭、更新换 Worker、缓存命中及历史缺字段。验证 IPC sender 和会话权限；外部媒体只走可信 Main 层及既有安全校验。为完成会话增加明确保留/清理策略，不清活动和收藏数据。

**输出：**生命周期与安全测试、数据留存说明、可回滚迁移说明。

**约束：**不关闭 CSP、webSecurity 或签名验证；不在日志记录 Key/图片 Base64；不把私人文本上传统计；不恢复取消的图像预检。

**退出条件：**无会话串写、无隐藏重试计费、无删除/升级后错误显示另一版案例、无内存监听泄漏。

### 步骤 9：分层验收和设计对照

**输入：**04-验收测试用例.md、现有测试命令、实际可运行环境。

**操作：**执行单元/组件/IPC/数据库迁移/非付费集成和 UI 测试，分别报告；在规定尺寸与 DPI 截图，逐组件对照 H01/H02。需要真实模型时先说明测试计划和预算请求授权。

**输出：**`implementation/03-测试报告.md`、`implementation/screenshots/`、性能记录、未执行/失败项。

**约束：**禁止用设计 PNG 作背景假装实现；没有实际 Chromium/Electron 验证不能标视觉通过；mock 译文/图片成功不能冒充真实公网服务验证。

**退出条件：**每项需求可追踪到测试和证据；阻塞问题不被“build 通过”掩盖。

### 步骤 10：交付与说明

**输入：**本轮改动、测试证据和剩余问题。

**输出：**`implementation/01-实施记录.md`、`02-配置迁移与回滚.md`、`04-审查与遗留项.md`；简短交付摘要说明文件、功能和验证方式。

**约束：**不自行 bump 版本、不提交/推送/合并/打标签/发布。数据库回滚不能要求用户直接删除整个 userData。对已写入新表采用保留式回退/兼容读取，不清空用户收藏和作品。

**退出条件：**用户可按路径复现操作并判断结果，知道什么已经完成、什么尚未测，不需要理解全部代码才能验收。
