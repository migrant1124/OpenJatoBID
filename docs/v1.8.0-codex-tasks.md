## 3. 已读取事实与仍需本地核实的事项

### 3.1 已读取事实

- `client/package.json` 的版本为 1.7.5；有 build、dev、test:update、test:technical-plan-guards、smoke:electron-native 等脚本。脚本存在不代表本次运行通过。[R2]

- AI 请求由现有 `aiService.cjs` 调度，图像生成有独立队列；后台任务使用 queueScope，不能从新组件直接绕过服务发 AI HTTP 请求。[R6]
- 现有 `promptLibraryStore.cjs` 已管理个人提示词、分组与收藏，必须兼容而不是另建隔离的重复个人库。[R7]

### 3.2 未验证，不得当作已具备

所有外部能力都必须区分“文档声明”“已写适配”“模拟测试通过”“真实接口通过”。只有前两项不能作为真实能力验收。

## 4. 实现路线与能力边界

### 4.1 复用优先，不新增低代码运行依赖

优先复用现有菜单、弹窗、配置、AI 队列、SQLite、提示词库、作品文件管理模式，以及上游的标准提示词数据。

可用现成模型或服务完成识图、优化、生成与拆层；无需自行训练模型。纯低代码工具不能替代此次已确认的 Electron 本地文件、局部选区、后台任务及 PSD 交付链路，因此这些连接与界面由 Codex 实现，不为此另加飞书／自动化平台作为用户必需依赖。

复用现有服务 → Codex 编写最小业务适配 → 本地 UI／存储 → 调用已验证能力 → 本地导出，是本版实现主线。

### 4.2 进程分工（新增路径为建议，非声称已存在）

| 层 | 职责 | 候选位置 |
| --- | --- | --- |
| Renderer | 三张页面、表单、参考图角色、预览与涂抹操作 | `client/src/features/image-studio/` |
| IPC/preload | 最小调用与任务事件桥接 | 新增 imageStudio IPC，扩展既有 preload 和类型 |
| Main 业务服务 | 草稿、任务编排、模型能力映射与版本链路 | `client/electron/services/imageStudio*.cjs` |
| AI 基础服务 | 统一队列、请求、统计、取消及重试策略 | 复用或最小扩展 `aiService.cjs` |
| 存储 | SQLite 元数据、持久化任务和磁盘图像文件 | 复用现有数据库迁移；独立模块命名空间 |
| 图像处理／PSD | 解码、合成、拆层验证与文件写入 | 耗时 CPU 工作放可取消的工作线程／已有后台机制 |

文件名由 plan 核实后固定。不要因为表里有多个服务名称就机械创建空抽象。不得把所有图片像素处理放在 Electron 主线程阻塞其他功能。

bridge 以当前本地实现为准：核对 `window.jatoaibid` 与 `window.yibiao` 的真实映射，兼容已有调用，不在此次任务里全仓库改名。

### 4.3 最小能力合同

至少识别以下能力：文字优化／翻译、图片理解、文生图、参考图生成、局部编辑、图片拆层。

同一渠道可提供多项能力，不要求为每项创建一套账户。模型名称只作配置值，不能靠名字猜支持能力。记录已验证的最大参考图数、输入格式、尺寸／比例、返回方式、异步任务查询、取消和原生 mask 情况。

未确定渠道时先形成配置说明和能力测试计划，不自动购买服务、注册账户、升级套餐或猜测 API。拆层模型是独立能力：普通识图模型或普通生图模型不能因共用兼容接口就被当作拆层服务。

### 4.4 数据最小集合

| 数据 | 必须保留的内容 | 关键不变量 |
| --- | --- | --- |
| 草稿 | 用户输入、参考资产及角色、设置、修订号 | 切页和重启可恢复；异步结果不覆盖更新后的草稿 |
| 任务 | 内部 ID、操作类型、快照、scope、外部任务 ID、状态 | 一次请求有可追踪身份；取消只影响本任务 |
| 结果／资产 | 文件 ID、哈希、尺寸、编码、时间、父版本 | 成功文件本地持久化；新版本不覆盖原文件 |
| 提示词快照 | 原输入、应用的优化稿、实际发送文本、使用配置引用 | 上游更新或个人库编辑不改变历史快照 |
| 远程提示词 | 来源 ID、记录 ID、原文哈希、来源链接、时间 | 与个人副本分开；失败不清空缓存 |
| 翻译 | 来源记录及版本、目标语言、翻译规则版本、结果 | 只对新增／变化内容翻译，按哈希复用 |
| 个人扩展／风格 | 与现有条目关联的用途、标签、参数等 | 兼容对话模式；删除和分组不误伤旧数据 |
| 拆层／导出 | 源版本、层资产、层序、实际尺寸、合成预览、文件记录 | 非空差异图层；不伪装原始可编辑文字 |

图像大文件放磁盘，SQLite 保存元数据和受控引用；不把大量 Base64 存入 localStorage，也不靠临时网址作为作品唯一来源。新增 JSON 可用于导出交换，但不能取代已规定的 SQLite 权威业务状态。

### 4.5 外部边界、人工确认与操作记录

在真正的不可信边界验证导入文件、模型返回、远程提示词 JSON 和外链下载；不在可信本地每层重复同一校验。限制资源大小、类型、路径与必要的网络目标；不把远程内容当 HTML、代码或 Agent 工具授权。

密钥仅在 Main 侧使用，遵循项目已有凭据方式。确需新加密存储时核对当前 Electron 支持，不能把 OS 加密吹成抵御同用户所有进程的绝对安全保障。[R10]

新模块不注入招标事实、固定公司品牌或竞争对手名单过滤规则。保留服务商适用规则、素材使用权提示及对外使用前的人审提醒；不建立新的投标式强制审批流程。优化应用、内容版本、请求与导出在本地可追踪，普通埋点只发既有允许的计数与状态，不上传 prompt、图片、密钥和本地路径。

| TC-11 | 来源相同记录内容变更 | 只更新远程缓存及受影响翻译，个人副本与旧任务快照不变 |
| TC-12 | 来源超时、坏 JSON 或翻译失败 | 保留最后成功缓存；显示真实失败／未翻译状态 |
| TC-13 | 个人库跨生图和对话模式编辑 | 同一条目一致；原导入、分组、撤销和 Agent 输入行为正常 |
| TC-14 | 应用常用风格 | 保留主体与参考图；不支持参数有说明 |
| TC-15 | 基于历史第二版继续生成 | 新父版本为第二版，使用该版快照而非最新输入 |
| TC-16 | 删除父版本，子版本仍存在 | 子版本可预览、追踪和继续使用，不误删被引用文件 |

```powershell
Set-Location 'D:\Documents\OpenJatobid\client'

```

这些命令的作用依次是：检查 TypeScript 与打包前端、回归更新逻辑、回归既有技术方案保护、检查 Electron 原生依赖、启动真实桌面程序供操作验证。实际仓库脚本与环境为准。[R2]

对新增 CommonJS 文件另做 `node --check`；具体文件名以实际改动为准。依赖更动时按仓库要求核对审计和原生 ABI，不通过删除锁文件或忽略安装失败掩盖问题。

| 证据层级 | 证明什么 | 不能证明什么 |
| --- | --- | --- |
| 静态／构建 | 语法、类型、构建链路 | 真模型、真实 UI、PSD 可打开 |
| 单元／合同 | 数据逻辑、输入输出、状态迁移 | 服务商真实支持 |
| 模拟接口 | 请求组织和异常处理 | 成本、效果、实际模型兼容 |
| Electron 运行 | IPC、文件、页面、任务和恢复 | 所有 Adobe 兼容性 |
| 真实外部接口 | 已配置渠道下的实际能力 | 其他未知渠道全部支持 |
| Photoshop 人工检查 | 被测版本／样本的真实 PSD 行为 | 恢复原作者工程或全部字体兼容 |

测试报告记录测试环境、命令、退出码、输入类型、实际结果、证据位置和未通过原因。截图、样例和日志必须使用获准测试素材并脱敏。

## 10. 性能、成本与停止条件

不写死未经验证的“几秒出图”“低成本”或“本机必能跑”。以实测记录生成耗时、下载时间、拆层时间、层数／尺寸、峰值内存和导出时间。

多层像素至少涉及宽×高×4×层数的原始数据量，实际峰值还含解码、合成和编码缓冲；必须实测并设置适当限额。不要为了本版本默认给每位员工下载大模型或新增 Python 运行环境。

以下情形暂停受影响任务而不是伪造成功：真实能力缺失；调用授权不足；接口合同未定；数据迁移可能误伤原库；设计未确认却需大范围 UI 变更；PSD 只有假层；测试环境不足却需作已完成声明。

## 11. 最终交付要求

交付代码差异、配置说明、必要依赖说明、迁移／备份与恢复办法、真实生成和 PSD 样例、分层测试报告、设计对照、只读 review 结果及剩余限制。
