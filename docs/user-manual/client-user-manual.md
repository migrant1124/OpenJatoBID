# Jato AI BID 客户端使用说明手册

适用对象：普通员工用户。

适用范围：员工客户端。本文不包含管理端部署、代码开发、密钥运维或发布流程。

版本说明：依据当前客户端开放入口编制。商务标、图片知识库、AI 评标、投标机会、资源下载等入口在当前阶段可能隐藏或暂未开放。

## 1. 快速开始

首次使用建议按下面顺序完成。

1. 安装并打开“佳图智能投标助手”。

2. 若当前电脑尚未授权，先提交授权申请，等待管理员审批。

3. 登录后进入设置，配置文本模型；需要自动配图时再配置生图模型。

4. 进入“标书生成”，选择“生成技术方案”或“已有方案扩写”。

5. 上传招标文件，按步骤完成解析、目录、全局事实、正文生成和导出 Word。

6. 导出后务必人工打开 Word，核对图片、表格、页眉页脚、承诺内容和签章材料。



## 2. 登录与授权

![员工登录界面](docs/secondary-development/design/screenshots/client-login-ant-1280x720.png)

图：员工登录界面

已经获批的员工在登录页输入姓名和手机号即可登录。软件会自动识别当前电脑设备，姓名、手机号和设备必须与管理端授权一致。

![授权申请窗口](docs/secondary-development/design/screenshots/client-authorization-modal-1280x720.png)

图：授权申请窗口

新员工、新电脑或授权失效时，点击登录页左下角“授权申请”。填写真实姓名、11 位手机号和管理员提供的局域网服务器地址，提交后等待管理员审批。

- 每名员工最多同时绑定 3 台有效电脑。

- 授权保存在当前电脑，本地离线可以继续使用，但至少每 30 天需要连接一次公司局域网管理端完成校验。

- 管理员撤销授权、授权到期或设备变化后，需要联系管理员处理或重新申请。



## 3. 主界面与菜单

![主界面和左侧菜单](docs/secondary-development/design/screenshots/client-main-1440x900.png)

图：主界面和左侧菜单

登录后，左侧是一级菜单，右侧是当前功能页面。普通用户常用入口如下：

- 标书生成：包含“生成技术方案”和“已有方案扩写”。

- 模板设置：管理 Word 导出模板和新建排版模板。

- 知识库：管理可复用的文档资料和案例素材。

- 标书检查：包含“标书查重”和“废标项检查”。

- 设置：配置模型、文件解析、更新和隐私信息。



如果某个功能入口在当前版本没有显示，通常表示该功能尚未开放，不影响已开放功能使用。

## 4. 基础设置

![设置页总览](docs/secondary-development/design/screenshots/client-settings-ant-1440x900.png)

图：设置页总览

首次生成标书前，建议先完成文本模型配置。模型配置只保存在当前电脑本地。

![文本模型配置](docs/secondary-development/design/screenshots/client-text-model-1440x900.png)

图：文本模型配置

### 4.1 文本模型

1. 打开“设置”。

2. 进入“文本模型”。

3. 选择服务商或填写 OpenAI Like 接口地址。

4. 填写 API Key 和模型名称。

5. 点击“测试”确认可用，再点击“保存”。



### 4.2 生图模型

如果希望正文生成后自动生成配图，需要配置生图模型。选择服务商后填写模型名称、API Key、Base URL 等信息，并先测试成功。生图模型不可用时，正文生成仍可继续，但会跳过自动配图。

### 4.3 文件解析

大多数 Word 或带文字层 PDF 建议使用“本地解析”。当本地解析失败、扫描件质量较差或版式复杂时，可尝试 MinerU 精准解析 API。xls/xlsx 表格类文件会优先走本地解析。

### 4.4 更新与隐私

![关于与隐私说明](docs/secondary-development/design/screenshots/client-about-privacy-1440x900.png)

图：关于与隐私说明

设置页底部可以检查软件更新，并查看数据与隐私说明。业务文档、API Key、方案正文和导出文件不会作为运维埋点上传到管理端。

## 5. 生成技术方案

![生成技术方案入口](docs/secondary-development/design/screenshots/client-technical-plan-1440x900.png)

图：生成技术方案入口

“生成技术方案”适合从招标文件开始编制一份新的技术方案。建议按页面底部的“下一步”顺序操作。

### 5.1 上传招标文件

1. 进入“标书生成 > 生成技术方案”。

2. 在 STEP 01 上传招标文件。

3. 确认文件名称和解析状态正常后，点击“下一步”。



### 5.2 招标文件解析

STEP 02 会并发解析招标文件中的关键项，例如项目概况、评分办法、工期、技术要求、废标风险和证明材料要求。通常使用默认解析项即可；如时间紧，可选择只解析关键项。

1. 点击“开始解析”。

2. 等待左侧解析任务完成。

3. 选择任一解析项，可以在右侧查看结果。

4. 关键解析项完成后进入下一步。



### 5.3 生成和调整目录

STEP 03 根据招标文件和解析结果生成技术方案目录。生成后请重点检查章节是否覆盖评分项、技术要求和强制响应内容。

- 可以调整目录层级、标题和顺序。

- 需要人工填写的承诺函、固定格式表格等章节，可标记为人工填写。

- 目录发生大调整后，旧正文和生成缓存可能需要重新生成。



### 5.4 设置全局事实

STEP 04 用于统一项目名称、工期、服务范围、人员安排、质量目标等全篇共享口径。全局事实越准确，后续正文越稳定。

### 5.5 生成正文与配图

![技术方案流程页面宽屏视图](docs/secondary-development/design/screenshots/client-technical-plan-1920x1080.png)

图：技术方案流程页面宽屏视图

STEP 05 按目录小节生成正文。正文任务在后台执行，页面切换不会中断任务。

1. 点击“生成正文”。

2. 如弹出正文生成配置，按需要设置目标字数、是否生成 HTML 图片、是否生成 AI 图片。

3. 若弹出“图片编排确认”，取消不需要的图片后点击确认。

4. 生成过程中可查看每个小节状态。

5. 生成完成后，逐节检查关键承诺、技术参数、工期和人员信息。



人工填写章节不会进入 AI 生成、扩写或自动改写流程，需要用户点击“编辑”后手动填写 Markdown 内容。

### 5.6 导出 Word

正文完成后，点击页面工具条中的“导出 Word”。如果系统要求选择模板，先选择已保存模板；没有模板时，到“模板设置”中新建并保存一个模板后再导出。

- 导出后请打开 Word 人工核对版式、图片、表格和目录编号。

- 强制证明材料缺失、废标风险或人工填写缺失不会因为导出而自动消失，必须由用户核对处理。

- 提交正式投标文件前，应再按招标文件要求核对签字、盖章、附件和格式。



## 6. 已有方案扩写

“已有方案扩写”适合已有一份技术方案，但内容太薄、论述不充分或需要按新招标文件扩充的场景。

1. 进入“标书生成 > 已有方案扩写”。

2. 上传招标文件和已有方案。

3. 按同样步骤完成招标文件解析、目录生成、全局事实和正文扩写。

4. 扩写结果应保持原方案真实可落地，同时补充细节、图表和响应内容。



扩写不是替代人工审核。涉及真实业绩、资质证书、人员证书、设备数量、承诺条款时，必须由用户确认。

## 7. 模板设置

![模板设置入口示意](docs/design-reference/模板设置.png)

图：模板设置入口示意

模板决定导出 Word 的页面、标题、编号、字体和表格样式。建议在正式导出前先准备一个常用模板。

1. 进入“模板设置 > 新建模板”。

2. 设置纸张、页边距、标题层级、正文样式和编号格式。

3. 通过右侧预览确认样式。

4. 保存模板后，可在“我的模板”中查看、编辑或删除。



## 8. 知识库

![知识库入口示意](docs/design-reference/知识库.png)

图：知识库入口示意

文档知识库用于保存可复用资料，例如公司介绍、服务案例、技术方案片段、设备清单、项目经验和标准响应内容。

1. 进入“知识库 > 文档知识库”。

2. 上传或维护可复用资料。

3. 在生成目录或正文时选择需要参考的知识库。

4. 定期清理过期资料，避免旧口径进入新标书。



知识库资料只是辅助参考。对于项目特定承诺、真实业绩和证照材料，仍以当前招标文件和公司实际情况为准。

## 9. 标书查重

![标书查重页面](docs/secondary-development/design/screenshots/client-duplicate-check-ant-1440x900.png)

图：标书查重页面

标书查重用于检查多份投标文件或同一文件内部的重复表达。可选上传招标文件，系统会尽量排除多份投标文件共同引用招标文件原文导致的重复。

1. 进入“标书检查 > 标书查重”。

2. 上传需要检查的投标文件。

3. 如有招标文件，可一并上传作为排除依据。

4. 点击开始分析，等待结果生成。

5. 按“目录”“正文”等结果分类查看重复风险。



查重结果用于辅助修改，不等同于第三方查重系统报告。正式提交前仍应按采购方或代理机构要求进行最终检查。

## 10. 废标项检查

![标书检查入口示意](docs/design-reference/标书检查.png)

图：标书检查入口示意

废标项检查用于辅助识别招标文件中的硬性条款、无效投标风险、证明材料要求和响应完整性问题。

1. 进入“标书检查 > 废标项检查”。

2. 上传招标文件和需要检查的投标文件。

3. 开始检查并等待结果。

4. 优先处理“必须满足”“否则废标”“无效投标”等高风险项。

5. 对系统提示的缺失材料逐项人工核对。



扫描件、图片附件或非文本内容可能无法完整解析。系统提示只能作为辅助线索，不能代替人工通读招标文件。

## 11. 常见问题

**无法连接局域网管理端**：确认电脑已接入公司局域网，检查服务器 IP、端口和管理端服务状态。

**有效设备已达上限**：联系管理员撤销不再使用的旧电脑，再提交当前电脑授权申请。

**文本模型测试失败**：检查 Base URL、API Key、模型名称和网络连接；确认服务商账号余额或权限正常。

**文件解析失败**：优先确认文件未损坏；Word/PDF 可尝试重新导出；复杂扫描件可尝试 MinerU 精准解析。

**正文生成很慢**：长标书会分章节后台生成，等待任务完成；不要频繁重置流程。

**导出的 Word 版式不符合要求**：先检查是否选择了正确模板；必要时在模板设置中调整标题、编号、页边距和字体后重新导出。

**生成内容与实际情况不符**：涉及真实能力、人员、业绩、设备、工期和承诺时，以人工核对为准，直接编辑正文或全局事实后重新生成。

## 12. 使用注意事项

- 不要把 API Key、业务文档、导出文件随意发送给无关人员。

- 生成内容必须人工复核，尤其是价格、工期、资质、人员、业绩、承诺函和废标条款。

- 不要在正文中承诺公司无法实际履行的服务、设备、人员或时间节点。

- 同一项目多人协作时，应约定谁负责最终 Word 合稿和提交前检查。

- 遇到授权、更新或模型配置问题，优先联系公司管理员或软件负责人。
