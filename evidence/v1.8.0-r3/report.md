# v1.8.0 R3 验证与交付记录（2026-09-26）

## 结论和边界

R3 **未完成、不可发布**。本轮在现有 `v1.8.0-Image-generation` 分支（起点 `ab6755831ceb52a0863af43d9656cea671b7d2de`）实现了可运行的文生图、图片反推、部分提示词与来源管理，以及 v34 持久化；但参考图生成、局部编辑、七源合法随包中文内容和真语义 PSD 均没有达到 Spec 合同。设计图、模拟测试、图片库写入和当前渠道单图成功，均不替代这些缺口。

本轮未创建/切换分支，未提交、推送、合并、重置、打标签或发布；未运行 `audit fix`。项目原有未跟踪的 R3 输入、设计资产及用户文件保持原状。执行状态只记在 `tasks/todo.md`。

## 已实现的可复用工作

- 保留原菜单/路由、`aiService` 全局队列、原 `promptLibrary`、IPC/preload、SQLite 和 `sharp`/旧 PSD writer；新增生图专属任务状态、请求配置快照、无自动重试、完成子图逐张落盘、导出 PNG/JPG/WEBP、参考图受管导入和视觉反推输入。
- 三入口的 Electron 页面可进入；三尺寸窗口中已显示中文八类预设、草稿、历史作品、个人提示词、风格、七源配置。优化/反推先展示候选、主动应用并可撤销；组名变更不丢生图条目；草稿修订冲突现保留双方并要求明确选择。
- 七源元数据、用户覆盖/停用/删除/恢复、候选 URL 只读检测、单源校验与原子刷新已接通。内容语义 hash 忽略上游纯时间戳变化；用户改址清旧成功时间；旧响应在改址/删除后丢弃。
- `client/package.json` 与 lock 同步为 1.8.0，管理端版本未动；旧 v1.8.0 文档只加替代提示。
